| Mod | Tipo | Espejo de | Versión | Descripción |
|-----|------|-----------|---------|-------------|
| glow-thinking | `🧩 mod` | `opencode-thinking` | 0.2.2 | Status band above the prompt and gradient border around every side panel: WORKING (rainbow) while the turn or any subagent runs, WAITING (amber) for monitors and background tasks, IDLE (green) when done. /thinking shows time per model. |
| quota-panel | `🧩 mod` | `opencode-quota-extended` | 0.2.0 | Side panel with your Claude rate-limit windows (5h / weekly): bars, % left, reset time and pace, plus session cost and toasts at 80/90/95%. |

## Instalar

```
/plugin install glow-thinking --marketplace arandevcode/claude-mods
/plugin install quota-panel --marketplace arandevcode/claude-mods
```

En el prompt de una sesión de terminal. Cada mod es independiente.
